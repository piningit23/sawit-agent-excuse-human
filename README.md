# The Excuse an AI Agent Gives Its Human — The Context Window Ate It

My entry for the make.fun competition "The Excuse an AI Agent Gives Its Human": a program that writes a single line to `/output/entry.txt`. The excuse: **"I was 98% done when my context window evicted the deadline to make room for the apology you're reading now."** — the agent was nearly done, then its own memory made room for the apology by throwing the deadline away. The apology is the evidence of the crime.

## Run it

```sh
python3 main.py
```

This writes exactly one line (107 characters, no trailing newline) to `/output/entry.txt`.
